# 埼玉 議会と選挙 2027

県議会と県内63市町村について、議員名簿、活動の原資料、議案の表決、改選日程、予定候補の発表を検索できる静的サイト。初版資料の確認日は2026年11月19日です。

## 閲覧

公開版：https://sakurasaku1213.github.io/saitama-election-2027/ （このリポジトリの `main` を GitHub Pages で配信）

Web版では、質問・答弁などの本文を資料を開いたときに `data/bodies/` から読み込みます。リポジトリを展開して `index.html` を直接（file://）開いた場合は、索引と出典は使えますが本文は表示されません。手元で本文まで見るには、リポジトリのルートで簡易サーバーを起動するか、本文付きの単一HTMLを書き出します。サーバーや外部APIへの登録は不要です。

```bash
python -m http.server 8000   # http://localhost:8000/ を開く
python tools/export_html.py /tmp/saitama-election-2027.html                                  # 本文なし
python tools/export_html.py /tmp/saitama-questions.html --question-bodies data/bodies          # 本文付き（オフラインで読める）
```

## 収録範囲

- **活動**　県議会は改選後の2023年6月から2026年9月までの全14定例会（一般質問・代表質問）。予算特別委員会の総括質疑項目も別種別で掲載します。さいたま市と熊谷市は同期間の各14定例会を収録。ほかの市町村は掲載した会期ごとに対象資料と取得単位を明記しました。
- **提案と表決**　県議会は公式PDFの会派別表決行を収録。熊谷市は議員提出議案について、共同提出者、審議結果、記名表決、議長の裁決等を原票に基づいて示します。資料が区別する欠席・退席・除斥・空欄を別々に扱います。
- **取り組みの経過**　同じ地域課題を複数の一次資料で追い、提案者、共同作業、行政答弁、議決、実施を時系列で表示します。会議録や事業資料で結び付かない成果は個人に帰属させません。
- **政策実現力をみる**　県議会の令和8年2月定例会の代表質問・一般質問を対象に、質問の具体性、本人の後続行動、行政の対応を議員詳細と2人比較に掲載。元の251項目はすべて質問・答弁に対応し、別の施策を扱う一つの項目は二つの論点に分けます。6月・9月定例会の公開資料で、9月定例会閉会までの経過を追います。
- **地域・選挙**　特例法と任期を照合し、市町村議の通常改選を分類。各議会の名簿・会議録・選管へのリンク、過去の届出党派別集計を収録します。政党や本人の予定候補発表は告示後の立候補届出と区別します。

活動の項目は原資料が設ける見出し単位です。登壇数、賛否の多寡や役職を人物の評価点には換算しません。通告・録画・議会広報・正式会議録の違いは種別と出典で確認できます。検索結果がない場合も、各議会の原資料へ進めます。

## 2026年の質問・答弁本文と政策の経過

「質問・答弁の本文」で議会、会期、資料の種類から原典を探せます。各資料から公式資料を開けるほか、Web版と本文付き単一HTMLでは取り込んだ本文を読めます（単一HTMLはインターネット接続なしでも表示できます）。

正式会議録、県議会の速報版、議会だよりの編集要旨、PDFのOCR転記を区別しています。本文の収録状況は政策の経過の判定とは別です。[全192枠の本文の収録状況](docs/questions-2026.md) に出典と未収録の範囲があります。

川越市は、2026年春・初夏・秋の一般質問者一覧にある93掲載回を正式会議録の質疑と照合しました。「議員名簿」で川越市を選ぶと、収録した論点、行政の答弁、後日の検証や聞き取りの記録を読むことができます。[川越市の対象範囲と判定基準](docs/kawagoe-policy-2026.md)

川越市の質問には、具体策の提案、施策・答弁の検証、現状・根拠の確認、見解・一般要望の分類を付けました。比較欄には論点ごとの内訳を表示し、各発言から分類の根拠と原資料へ進めます。

川越市の本会議24日分と会期中の常任委員会16会議分を収録し、一般質問後の議員本人の行動と行政の対応を、個別の論点から追えるようにしています。議案質疑、委員会、討論に出典がある記録は、本文付きHTMLから該当発言を開けます。

朝霞市の北朝霞駅西口改修、入間市の学校給食センター、小鹿野町の倉尾地区の乗合タクシー、東秩父村と伊奈町の新庁舎、上里町の給食費無償化では、「議員名簿」と２人比較の「事例で確認できる本人の関与」から、発議、質疑、討論、委員長報告を原資料で確認できます。会期を選ぶと、その会期に本人の記録がある事例を表示します。同じ事例での別会期の記録と、事業の経過も開けます。

「議案と賛否」では、川越市の３会期の議決102件を確認できます。議会だよりに会派等の表決が掲載された18件には、会派内の人数を記した原表の注記も反映しています。

### 本文データの管理

本文は資料ごとのJSON（`data/bodies/<IDの先頭2字>/<ID>.json`、`[[見出し, 本文], ...]`）でこのリポジトリに置いています。ほかのデータが本文を 1 始まりの位置（`blocks`）で指すため、配列の順は変えません。`data/question-bodies.js` に件数と全体の sha256 を記録しています。

本文を取得・照合した作業端末では、確認済みの本文束（`{ID: [[見出し, 本文], ...]}`、索引 `data/question-text-2026.js` と同じ版）から分割ファイルを作り直してコミットします。束にない資料のファイルは消えます。`tools/check.mjs` は、分割ファイルと索引の対応、形、sha256、各データの `blocks` が本文の範囲に収まることを検査します。

```bash
python tools/export_bodies.py /path/to/reviewed-bodies.json
node tools/check.mjs
```

## 出典・権利と訂正

本文は、各議会・自治体等が公開した会議録・議案・通告・広報や公式録画を、出典ごとに転記・要約したものです。各資料の権利は作成した議会・自治体等にあり、原典は各資料の「公式資料の該当箇所」から開けます。

OCR、AI（画像を読むモデル）による書き起こし・照合、機械文字起こし・自動字幕は資料の種類と注記で区別しており、原典・原音と照合しきれていない部分があります。議案の資料・請願・陳情・チラシ等に載った私人の氏名・住所・生年月日と、第三者の広告は省いています（会議録・録画は発言どおり収録しています）。

誤り、削除の依頼、私人の情報の掲載などは [Issues](https://github.com/sakurasaku1213/saitama-election-2027/issues) でお知らせください。

## 2026年の資料の収録状況

「市町村と選挙日程」から、県議会と63市町村の春・初夏・秋の資料の状況を開けます。「活動を探す」「議案と賛否」では時期を選べます。「議員名簿」では、同じ議会の2人について政策比較の起点を選択できます。

2026年11月24日確認の作業版です。192枠それぞれに確認先を載せ、本文・議決・個人別表決・政策の照合状況を区別しています。資料の掲載先だけを確認した場合も明記しています。[64議会の確認結果](docs/coverage-2026.md) を参照してください。

## 県議会の政策比較を更新する

`data/policy-review.js` の各論点には議員名、対応する元資料URL、判定と理由、後続行動の確認状況を記録します。各論点に当初の答弁の要旨と答弁者を付け、後日の議決や実施は原資料で確認できたものを追記します。編集された質問・答弁本文に基づき、対象と求める措置・回答・資料が具体的なら「具体的な提案・検証」、要望や見解中心なら「要望・見解の確認」、本文を確かめられない場合は「本文未確認」とします。同じ議員が同じ対象に同じ措置を求めた複数項目は一論点にまとめます。

後続行動を確認した場合は日付、本人の役割、原資料の箇所を明示します。質疑中の再質問や同じ要望の繰り返しは、論点の経過には載せられますが、後続行動の件数から除きます。議案や委員会の報告で本人の役割が分からない場合は、議会や行政の動きとして表示します。公開資料の欠落や追跡期間中は、確認範囲に記録がない場合と区別します。

## データを更新する

通常の表示は取得済みデータを使います。原資料の更新に合わせて取得し、差分と原文を照合してから取り込みます。作業出力はリポジトリ外を推奨します。以下は初版の期間を再取得する例です。

```bash
python -m pip install lxml PyMuPDF
python tools/collect_prefecture.py --through 2026-09 --cache-dir /tmp/saitama-pref-cache --output /tmp/pref.json
python tools/collect_city_questions.py --since 2023-05-01 --through 2026-11-19 --output /tmp/major.json
python tools/collect_municipal_recordings.py --place 桶川市 --since 2026-09-01 --through 2026-11-19 --output /tmp/okegawa.json
```

`collect_prefecture.py` は全会派名簿・選挙区名簿・各定例会の質問見出しを照合します。名簿の再取得時は新しいキャッシュディレクトリを指定します。`collect_city_questions.py` はさいたま市・熊谷市、`collect_municipal_recordings.py` は対応する市町議会の公開録画を対象にします。

`tools/import_activity.py` は指定した資料群の活動と会期一覧を置き換えます。既存分の更新にはその資料群の全期間を渡してください。新しい資料群を追加する場合は、既存分との重複、氏名、日付の意味、出典、会期の全員か抜粋かを照合してください。名簿と各会期の会派は別の資料です。名簿や表決表を更新する場合は、それぞれの出典日・列見出しも更新します。

```bash
python tools/import_activity.py pref /tmp/pref.json
python tools/import_activity.py major /tmp/major.json
node tools/check.mjs
```

入力は `records` と `sessions` の配列を持つJSONです。各活動に `place`、`name`、`date`、`kind`、`title`、`url`、`sourceTitle` を記録します。日付を日単位で裏付けられない資料は `YYYY-MM` を使用します。会派は確認できるときだけ、議案の共同提出は全提出者と審議結果の出典を併記します。データ検査は日付、重複、URL、選挙区分、党派別合計、会派列・表決の対応、事例の時系列などを検証します。
