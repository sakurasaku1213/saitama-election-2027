# 埼玉 統一地方選2027 総合情報

2027年統一地方選（埼玉県議会議員選挙・埼玉県内全63市町村の議会議員選挙）の総合情報サイトです。

- 埼玉県議選：2027年4月11日（日）投票
- 市町村議選：2027年4月25日（日）投票（一部の自治体は任期の関係で対象外）

## 内容

- 選挙日程と投票日までのカウントダウン
- 埼玉県議会の会派別勢力図
- 政党・会派の立場を同じ形式で比べる比較表
- 県内40市＋22町1村すべての現職情報（会派構成・議員名・役職など、公式資料で確認できる事実）
- 任期がずれて2027年4月に選挙がない自治体の明記
- 無党派層向けの投票ガイドとFAQ

各党・各議員を同じ物差しで並べ、検証可能な事実と出典に基づいて客観的にまとめることを方針としています。候補者の公認発表が出るたびに更新します（情報基準日はサイト内に表示）。
